Your link shows the wrong picture or an old title when shared

You paste your website into Facebook, LinkedIn, WhatsApp or a text message and the preview card shows your logo cropped badly, a random photo from the footer, no picture at all, or a title you changed months ago. The card is not taken from the page you see. It is built from a few hidden og: tags in the page's code, and each platform keeps its own copy for days or weeks. Fix the tags, then make each platform fetch again.

What the checks found


  





Why it happened (five minutes)


    
  
  1. Read what the platforms read. Paste your address into Facebook's Sharing Debugger or LinkedIn's Post Inspector. Both show the title, description and image they found, plus any warnings. This is the test that matters: your own browser shows the page, not the card.
    2. 
  
  2. Is there an og:image at all? In the page source (Ctrl+U) search for og:image. With none, each platform guesses, and it often picks a logo, an icon or the first picture in the footer.
    3. 
  
  3. Two sets of tags? An SEO plugin (Yoast, Rank Math, All in One SEO) plus a theme or a "social share" plugin can each print their own og: tags. Platforms usually take the first one, which may be the stale one.
    4. 
  
  4. Tags right, card still old? Then it is the cache. Facebook and LinkedIn keep a copy of the card for about a week; WhatsApp and iMessage keep their own copy too. Nothing changes until they fetch again.
    5. 
  
  5. Image set but not shown? It is too small (under 200 by 200 pixels), too large (over 8 MB), on an http:// address, or a security plugin or Cloudflare rule turns the platform's fetcher away.
    6. 




Fix it, safest first


    
  
  1. Set one share image for the whole site. Yoast: SEO, Settings, Site basics, "Site image". Rank Math: Titles & Meta, Global Meta, "OpenGraph Thumbnail". Use a 1200 by 630 pixel JPG or PNG with the important part in the middle, so square crops still work.
    2. 
  
  2. Set it per page and post. In the editor, the SEO plugin's Social tab takes a title, description and image for that page. With nothing set, most plugins fall back to the featured image, so give every post one.
    3. 
  
  3. Remove the duplicate tags. If the page source shows two og:image lines, turn off the Open Graph or social option in the theme or the extra plugin and leave the SEO plugin in charge.
    4. 
  
  4. Clear your own caches, then view the page source again and check the new tags are there: a caching plugin or Cloudflare can keep serving the old code to the platforms.
    5. 
  
  5. Make each platform fetch again. Facebook Sharing Debugger: Scrape Again (twice for a new image, the first fetch can come back without it). LinkedIn Post Inspector: Inspect. WhatsApp and iMessage can hold the old card a while; sharing the address with ?v=2 on the end makes them fetch a fresh one.
    6. 
  
  6. Confirm. The debugger should show your title, description and image with no og:image warnings.
    7.

What not to do


    
  
  • Do not install another plugin "to fix sharing". More plugins printing tags is usually the cause, not the cure.
    • 
  
  • Do not delete and re-post the link over and over. The platform reuses its cached card until it fetches again.
    • 
  
  • Do not put a phone number or text near the edges of the share image. Each platform crops the card differently.
    •
