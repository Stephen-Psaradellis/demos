WordPress theme install error: "The theme is missing the style.css stylesheet"

You upload a theme zip and WordPress stops with "The package could not be installed. The theme is missing the style.css stylesheet." Or a theme shows up under Appearance, Themes as "Broken Themes" with "Stylesheet is missing." The theme is usually fine. WordPress just cannot find its style.css where it expects it. Here is how to tell which case you have, and the fix for each.

What the owner sees

harborbakery.example/wp-admin/update.php?action=upload-theme

What the checks found


  





Find out which case it is (five minutes)


    
  
  1. Open the zip on your computer. A good theme zip holds one folder (for example harbor/) and directly inside it a style.css whose top comment starts with Theme Name:. If the zip holds another zip, or a folder inside a folder, that is the fault.
    2. 
  
  2. Is it a "full package"? Themes bought on ThemeForest and similar marketplaces download as a package: documentation, licence, demo content, child theme, and the real theme zip. Uploading the whole package gives exactly this error.
    3. 
  
  3. Is it really a theme? A plugin zip (it has a .php file with Plugin Name: and no style.css) belongs under Plugins. A GitHub source download (named like theme-main.zip) may hold build files rather than the theme itself.
    4. 
  
  4. "Broken Themes" in the list? Then the files are already on the server. In the host's File Manager or FTP, open wp-content/themes/ and look inside the named folder: style.css should be right there, not one folder further down.
    5. 




The fixes, by case


    
  
  1. Marketplace package: unzip the download on your computer. Upload the inner zip named after the theme (ThemeForest calls it "Installable WordPress file only"). Install the parent theme first, then the child theme zip if you want one.
    2. 
  
  2. Folder inside a folder: re-zip so the zip holds one folder with style.css directly inside. On the server, move the inner folder's contents up one level, then reload Appearance, Themes.
    3. 
  
  3. It is a plugin: upload it in Plugins, Add New Plugin, Upload Plugin instead.
    4. 
  
  4. Child theme shows "The parent theme is missing": the child's style.css has a Template: line naming the parent folder. Install that parent theme (same folder name) and the child works.
    5. 
  
  5. Upload fails part-way or the zip is very large: the host's upload limit cut it off, so WordPress unpacked half a theme. Upload the theme folder by FTP or File Manager into wp-content/themes/ instead, then activate it.
    6. 
  
  6. You edited style.css: the top comment must still start with /* and contain Theme Name: Something. A file saved with a byte-order mark or a deleted first line hides it. Re-download the theme rather than patching it.
    7.

What not to do


    
  
  • Do not download a "nulled" copy of a paid theme to get one that installs. Those copies are one of the most common ways WordPress sites get hacked.
    • 
  
  • Do not create an empty style.css to make the error go away. WordPress will list a theme that has no templates and your site will break when you activate it.
    • 
  
  • Do not activate a half-uploaded theme on a live site. Check it in Appearance, Customize (Live Preview) first.
    • 
  
  • Do not keep uploading the same zip. If it failed once, it is packed wrong, and every try can leave another half-made folder in wp-content/themes/.
    • 



Most cases are one zip opened and one folder moved. If the theme still will not install, that is what the box below is for. Related: "The plugin does not have a valid header", "Incompatible archive", "Destination folder already exists".
