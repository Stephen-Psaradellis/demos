WPBakery Page Builder won't load (or the button is gone)

You open a page and the blue "WPBakery Page Builder" button is missing, or the Backend Editor shows an empty grey box, or the Frontend Editor spins forever. Sometimes the page itself shows raw codes like [vc_row][vc_column] instead of the design. WPBakery usually comes bundled with a theme bought on ThemeForest, so it often lags years behind WordPress, and most of these failures trace back to that, to one setting, or to a background request being cut off. Visitors may still see the site normally. Below is a rebuilt example (not a real client), two checks, and the fix for each cause.

Edit Page

What the checks found


  





Check 1: which version, and is it allowed here?


In the dashboard go to Plugins and note the WPBakery Page Builder version, then Dashboard > Updates for your WordPress version. Then open WPBakery Page Builder > Role Manager and, for your role (Administrator, Editor), look at Post types, and WPBakery Page Builder > General Settings for the "Disable Gutenberg Editor" box.


    
  
  • The button is missing entirely: the block editor took over the page, or Role Manager does not allow the builder on this post type or role. First two rows of the table.
    • 
  
  • The button is there but the editor never finishes loading: an old bundled version, PHP limits, a plugin, a speed setting or a firewall. Check 2 tells you which.
    • 




Check 2: the browser's Console and Network tabs


On a computer, open the stuck editor, press F12 (or right-click and choose Inspect), open the Console tab and reload. Read the first red line and the file name next to it. Then open the Network tab, type admin-ajax or post.php in the filter box, press Update on the page, and read the Status column of the rows that appear.

Check it worked


Open two or three pages in both the Backend Editor and the Frontend Editor, including the longest one, change a word, press Update, and reload the public page to see it. Empty your cache plugin and the host's cache if the change does not show (changes not showing on the live site). Look at the Console once more: no red lines from js_composer.



What not to do


    
  
  • Do not delete WPBakery to "start fresh". Your layouts are stored as those [vc_...] codes inside each page, and without the plugin every page shows them as raw text.
    • 
  
  • Do not install a "nulled" WPBakery from a download site to get a newer version. They are a common way sites get hacked (hacked site redirecting); update through the theme or a licence.
    • 
  
  • Do not keep pressing Update on a long page that loses rows: each save can drop more of it. Fix max_input_vars first, then restore the page from its revisions.
    • 
  
  • Do not switch the security firewall off for the whole site. Allow the one rule for the one request.
    •
