More fixes

WooCommerce My Account pages or order received page show 404

The My Account page opens, but clicking Orders, Downloads, Addresses or Account details gives Page not found. Or the Lost password link 404s, or customers pay and land on a 404 instead of the Order received thank-you page. These are WooCommerce endpoints: extra addresses added to the end of a page, such as /my-account/orders/. Two checks tell you whether WordPress forgot those addresses or the page they hang off is set wrong.

Customer clicks

What the checks found


  





Check 1: save the permalinks once


In WordPress, go to Settings > Permalinks and click Save Changes without changing anything. This rebuilds the list of addresses WordPress knows, including every WooCommerce endpoint. Then open the broken link again in a private window. If it works now, the list had gone stale, usually after a plugin update, a site move or a change to the account page's slug. If it still 404s, go to Check 2.



Check 2: are the pages and endpoints set right


Go to WooCommerce > Settings > Advanced. Under Page setup, My account page and Checkout page must point at the real, published pages, not a deleted copy or a draft. Below that, under Account endpoints and Checkout endpoints, each box (orders, downloads, edit-address, lost-password, order-received) must hold a plain word. An empty box, a space, or two endpoints using the same word all break that link. Then open the My Account page in the editor: it must contain the My account block or the [woocommerce_my_account] shortcode. A page builder layout with only a login form does not draw the endpoints.

Check it worked


Log in as a test customer in a private window and click every tab on My Account, then log out and use Lost password. Place one test order (cash on delivery or the gateway's test mode) and confirm it lands on the Order received page with the order number. Clear the site and host cache afterwards so no one is served the old 404.



What not to do


    
  
  • Do not delete and recreate the My Account page without updating Page setup. The new page gets a new address and every endpoint stays broken.
    • 
  
  • Do not cache the My Account or Checkout pages. Customers would see each other's account pages or a stale 404.
    • 
  
  • Do not install a redirect plugin to send the 404s to the home page. It hides the problem and customers still cannot see their orders.
