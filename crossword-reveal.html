Crossword with unlocking clues

Fill the three Across answers. When they are right, a new row of the grid and four new clues appear. One square in the new row is a rebus: it holds two letters.

      How it is built: the whole puzzle (grid, answers, clues, and which stage each one belongs to) is one small data block at the top of the script, so a mock-up from a spreadsheet maps straight onto it. Stages unlock on any rule you like: a set of answers correct, a single word, or a share of the grid. Runs as one static page that works on phones, no server or account needed. Built by an AI system that I run and check myself.
